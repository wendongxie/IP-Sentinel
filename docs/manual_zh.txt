# 第一章 软件介绍
IP Sentinel 用于查看 Windows 电脑访问公网时使用的出口地址。家庭宽带、办公网络和代理环境均可使用。程序分别探测 IPv4 和 IPv6，记录出口变化，并查询国家、地区、ASN 和运营商。
启动后默认每小时检测一次。发现同一协议的出口地址变化时，程序可显示 Windows 托盘通知，也可向已配置的 Telegram 会话和企业微信群发送告警。
本手册适用于文东工作室出品的 V1.2.0。支持 Windows 10 1809 及以上版本和 Windows 11 的 x64 系统。安装版和便携版均自带运行依赖。

## 安装版操作
1. 从发布目录获取 IPSentinel_Setup_v1.2.0.exe。可用同目录的 SHA-256 校验文件核对下载完整性。
2. 双击安装包，按中文向导操作。若出现目录页，可点“浏览”选择位置。默认勾选“创建桌面快捷方式”，只从开始菜单启动时可取消勾选。
3. 核对选项并点“安装”，复制完成后点“完成”。从桌面或开始菜单打开 IP Sentinel。开始菜单也提供“IP Sentinel 用户使用手册”。
## 便携版与升级
1. 将 IPSentinel_Portable_v1.2.0.zip 完整解压到普通文件夹。打开解压后的 IP Sentinel 文件夹，再双击 IP Sentinel.exe。请保留同目录的 _internal；在压缩软件中直接运行可能缺少 HTTPS 探测所需文件。
2. 升级前，在 Windows 通知区域右键旧版图标并选择“退出”。安装版可覆盖安装；便携版可解压到新文件夹后启动。仅关闭窗口时，旧版仍可能在托盘运行。
安装版和便携版在同一台电脑、同一 Windows 账户下共用历史与通知凭据。换电脑时，请参照第十一章转移历史并重新填写凭据。
## 卸载
先从托盘退出。Windows 10 打开“设置 → 应用 → 应用和功能”；Windows 11 打开“设置 → 应用 → 已安装的应用”。找到 IP Sentinel 后点击“卸载”，按中文提示确认。卸载移除安装文件和安装器创建的快捷方式，历史和凭据会保留。便携版退出后可删除其解压文件夹。
# 第三章 软件主界面
“当前出口”按 IPv4、IPv6 分区显示地址、探测来源、国家、地区、城市、ASN、AS 组织、运营商和风险标签。顶部显示最近一次检测时间。启动后默认运行每小时监控，底部状态栏显示运行和本次任务结果。
点击“立即检测”可手动触发一次。点击“凭据与通知设置”可配置机器人和可选风险服务。点击“关于软件”可核对版本和出品方。关闭窗口后，程序可继续在 Windows 通知区域运行。

# 第四章 公网 IP 检测方法
1. 先连接预期使用的网络，再打开“当前出口”，点击“立即检测”并等待状态栏结束。
2. 分别查看 IPv4 和 IPv6。显示地址说明对应端点观察到了该协议的出口。显示“本次未观测到”说明该协议的探测没有取得可用结果，可能涉及协议支持、DNS、代理或端点可达性。
3. 在对应协议段查看国家、地区、ASN 和运营商。缺少归属资料时，这些字段会显示“未知”。地址仍可能已成功检测。
4. 检查分流时，记下程序显示的探测来源，在采用预期网络设置的客户端访问同一探测地址，对照同一协议、相近时间的结果，也可检查代理客户端是否记录了该端点的出站连接。
切换代理节点后，两个节点可能共享出口，或程序访问探测站点的流量受分流规则影响，仍走原出口。浏览器扩展里的代理规则通常只影响浏览器。IPv4 和 IPv6 也可能采用不同路径。
# 第五章 风险来源与费用
## 如何阅读风险结果
先看地址所属协议和数据来源，再看风险标签。地理位置是数据库估计，ASN 用于识别承担网络路由的自治系统。机房、VPN、代理和 Tor 标签描述已知用途或来源证据。软件未提供综合纯净度评分。
[表:标签]
## 免费公开名单
免费名单无需注册、购买或填写 IPWhois Pro API 密钥。程序下载 Tor Project 的出口名单，以及 MISP 的 IPv4 和 IPv6 已知 VPN 网段、机房或 VPN 混合网段。地址与名单在本机匹配；名单下载请求不会提交待查地址或机器人凭据。
初次启动时后台准备名单，之后每 12 小时尝试刷新。更新失败时继续使用最近一次有效缓存。首次结果显示未知时，可稍后点“立即检测”。查看来源和版本或获取时间；若某来源不覆盖该协议，该项会显示未知。
混合网段命中说明该地址出现在机房或 VPN 的混合范围，无法单独认定其用途。普通代理主要依赖具备相应证据的接口字段。公开名单和付费接口分别展示；即使二者结论不同，也应分别按来源理解。
## 付费选项 IPWhois Pro API
IPWhois Pro API 是第三方收费服务，由 IPWhois 计费。它是可选数据源。即使留空，软件仍可检测公网 IP、查询免费归属、匹配公开名单、保存历史，并按已配置渠道发送地址变化告警。

# 第六章 每小时自动监控
启动程序即开启监控，同时执行一次初始检测。运行期间默认每小时检测一次。“立即检测”额外触发一轮，定时节奏不随手动操作重置。最近检测时间在“当前出口”顶部，后续记录在“历史与统计”。
V1.2.0 未单独显示下次计划时间，也未在历史中标记每条记录的手动或自动来源。可以看历史时间与大致一小时间隔。休眠、关机、注销或程序退出期间不会持续采集，也无法补齐该时段全部变化。
关闭窗口后，从 Windows 通知区域的托盘图标重新打开，折叠图标可从“︿”查找。再次运行开始菜单或桌面入口也会打开现有窗口。完全停止监控时，在托盘菜单选择“退出”。
# 第七章 IP 变化历史与通知
IPv4 和 IPv6 各自以最近一次成功观测的地址为基线。同一协议首次检测成功只建立基线。连续两次有效观测地址不同才记为变化；中间的探测失败保留上一次的有效基线。
打开“历史与统计”，按 IP 或片段输入查询条件。表中的“原 IP”和“出口 IP”可对照旧地址和新地址，变化时间是该次检测的时间。“双击记录”可查看数据来源、标签和探测失败原因。该版本只记录观测时间，未单独存储变化真正发生时间或确认时间。
“导出 CSV”导出当前查询的全部匹配记录，包括 UTC 时间和证据 JSON。空查询会导出全部。各通知渠道的即时发送结果显示在状态栏。当前版本未持久化通知发送日志。

# 第八章 Telegram Bot 配置
## 创建和启动机器人
1. 打开 Telegram，在搜索中找到官方 @BotFather，可从 Telegram 官方文档进入。打开会话并发送 /newbot。
2. 按提示为机器人填写易辨认的显示名称。随后选一个可用的用户名，通常以 bot 结尾，使用拉丁字母、数字或下划线。
3. 创建成功后私下保管 BotFather 返回的 Bot Token。Token 相当于机器人的访问凭据；泄漏时在 BotFather 重新生成，再更新程序设置。
4. 在私人会话中打开自己的机器人，点击开始或发送 /start。发往群组时，先将机器人加入目标群并确认允许发送消息。为了让开启隐私模式的机器人收到用于确认的群消息，可向它发送带机器人用户名的命令。
## 获取目标 Chat ID
如果已经知道目标会话的 Chat ID，可直接填写。同一会话的 Chat ID 一般只需查一次，更换机器人的 Token 后可继续使用原 Chat ID，只要新配置仍指向该会话且机器人有发送权限。
如果不知道 Chat ID，先给自己的机器人发一条消息，再由 Telegram 官方 API 返回该会话的 chat.id。机器人无需回复。私人会话一般为正数，群组为负数，超级群组通常以 -100 开头。复制数字时保留负号；from.id 是发送人 ID，机器人用户名也不能当作私人会话的 Chat ID。
在本机 PowerShell 中运行以下例子。凭据通过隐藏输入提供，只请求 Telegram 官方 API。返回的会话数据仅作本地核对，勿分享完整响应。
[代码开始]
$secret = Read-Host "输入 Bot Token" -AsSecureString
$token = [System.Net.NetworkCredential]::new("", $secret).Password
try {
    $api = "https://api.telegram.org/bot$token"
    $updates = Invoke-RestMethod "$api/getUpdates" -ErrorAction Stop
    $updates.result | ForEach-Object { $_.message.chat } |
        Where-Object { $_ } | Select-Object id, type -Unique
} catch {
    Write-Warning "查询失败，请检查网络、Token 和机器人 Webhook。"
} finally {
    Remove-Variable token,secret,api,updates -ErrorAction SilentlyContinue
}
[代码结束]
查询没有返回 ID 时，给机器人再发一条消息并重试，核对输出中的 id 和 type。已有接收程序可能先取走更新。机器人已配置 Webhook 时，请从既有接收端获取 message.chat.id，保留正在使用的集成。
## 在 IP Sentinel 中启用和验证
1. 打开“凭据与通知设置”。在“Telegram Bot Token”填入 Token，在“Telegram Chat ID”填入完整的数字 ID，然后保存。两项同时有效即启用发送。
2. V1.2.0 暂无“测试发送”按钮。需要独立验证 Bot 时，可将目标 Chat ID 与 Token 交给官方 sendMessage 接口，自行向目标会话发送一条不含 IP 的测试文本。
3. 验证软件的真实告警时，先手动建立成功基线，再在自己控制的网络上切换到确认不同的出口，点击“立即检测”。确认历史出现原 IP 后，到目标会话核对文本，并看状态栏中的发送结果。
## 常见问题
400 通常需核对 Chat ID、目标是否存在以及请求内容。401 优先核对 Token。403 通常涉及机器人被屏蔽、被移除或缺少发送权限。429 表示触及服务频率限制，应等待服务给出的重试时间。
网络超时或 API 无法连接时，检查运行 IP Sentinel 的 Windows 会话能否访问 Telegram API。若外部测试成功却没有变化告警，确认历史是否出现变化记录。首次成功、同一出口或本次探测失败都不会发送变化通知。
参阅 Telegram 官方 BotFather 指南与 Bot API。
https://core.telegram.org/bots/features#botfather
https://core.telegram.org/bots/api#getupdates
https://core.telegram.org/bots/api#sendmessage
# 第九章 企业微信群机器人配置
## 准备企业微信群
此接口用于企业微信群的自定义消息推送。请准备允许添加群机器人且自己有相应权限的企业微信群，确认群成员同意接收网络地址变更告警。
腾讯文档以 PC 客户端 5.0 为例，在目标群的聊天信息管理区域寻找“消息推送”，再进入“自定义消息推送”。其他版本可能显示“添加群机器人”，位置随客户端和组织权限变化。若看不到相关入口，请让群主或企业管理员确认该群是否支持、组织是否开放及当前账号是否有权限。
## 创建机器人并取得 Webhook
1. 在目标企业微信群打开受支持的消息推送或机器人菜单，选择添加自定义推送或新建群机器人。
2. 按客户端要求填写名称，可用“出口监控”。如界面要求头像或简介，按组织规范补充。
3. 完成创建后，在机器人详情中复制完整的 HTTPS Webhook。地址通常包含 qyapi.weixin.qq.com 及 key 参数。创建者通常可以再次打开机器人详情查看。
4. 将完整地址保存在受控位置。同一 URL 可授权向该群发送消息，勿转发给他人或贴入公开网页、工单、截图。发生泄漏时，通过群管理处理旧机器人或更新推送地址后重新填写。
## 在 IP Sentinel 中启用和验证
1. 打开“凭据与通知设置”，在“企业微信机器人 Webhook”粘贴从企业微信复制的完整地址并保存。该字段有效且已保存即启用发送。
2. V1.2.0 暂无“测试发送”按钮。如需独立验证，按官方接口文档向自己的 Webhook 提交一条无敏感数据的文本 POST，检查返回的 errcode 是否为 0，并在目标群确认。不要把完整地址提交给第三方测试网站。
3. 在应用中先建立成功基线，再切换到不同的可验证出口并手动检测。在“历史与统计”确认旧、新 IP，然后查看企业微信群与应用状态栏。

## 常见问题
地址格式错误时，回到机器人详情重新复制，检查是否为 HTTPS 和完整 key。旧机器人被删除、变更或禁用时，需要管理员确认机器人状态并获取可用地址。组织或群限制无法由客户端解除。
HTTP 请求成功也可能收到非零业务错误码，应用会显示服务拒绝。核对企业微信返回的错误和群配置。遇到发送过频，降低测试频率。遇到超时，确认本机可连接企业微信机器人 API。
独立测试成功而应用未发送时，检查是否已经保存正确 Webhook，是否有实际旧、新 IP 变化，以及是否只发生在探测失败或同一出口的情况下。

# 第十章 通知消息说明
Telegram 和企业微信消息按 IPv4、IPv6 分段，列出检测时间、原 IP、新 IP、新出口归属及风险证据。公开名单证据显示来源和版本或更新时间。缺失信息显示为未知。Windows 托盘保留简短的地址变化摘要。检测时间是程序观测到变化的时间。
Telegram 与企业微信可以同时配置。Windows 本地通知通过系统托盘显示，受 Windows 通知设置影响。状态栏可查看各外部渠道本次发送是否被服务接受，服务接受和成员实际阅读是不同事件。
# 第十一章 软件设置与数据管理
本版随启动自动监控，托盘“退出”可停止。界面未提供独立监控开关、代理编辑器、开机自启开关和专用日志查看器。应用使用其 HTTP 客户端可访问的网络路径。连接问题可先看“当前出口”各来源的报错与状态栏。
通知配置保存在当前 Windows 用户的凭据管理器。清空相应字段再保存可停用该渠道并更新存储。推荐使用可信密码管理方式另存机器人的凭据，以便换机时重新设置。
本地历史位于 %LOCALAPPDATA%\IP Sentinel\history.sqlite3。公开名单缓存位于同一目录下的 risk-lists 文件夹。备份时先从托盘退出，再将 SQLite 文件复制到备份位置。需要恢复时先关闭程序，并保留一份当前数据库副本。导出的 CSV 适合查看和分析，当前版本不支持用 CSV 恢复历史。

# 第十三章 隐私与安全
程序本地保存检测时间、两种协议的出口地址及变化、归属和风险证据。探测端点会看到访问来源，归属服务会收到待查询的公网地址。启用外部通知后，Telegram 或企业微信会接收变化时的旧、新公网地址。
Bot Token 和机器人 Webhook 由 Windows 凭据管理器保存。安装包、便携包和应用可执行文件均不包含个人 Bot 凭据或历史。导出的 CSV 可能包含 IP、时间及网络归属，请根据收件人权限决定分享范围。截图前遮挡地址及凭据。
